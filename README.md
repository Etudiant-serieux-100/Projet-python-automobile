# Projet-python-automobile
Projet de python rendre le 4 Dec superbement exécuté. Il s'agit d'un jeu de voiture en 2d 2 joueurs comprenant le dérapage et le comportement de la voiture réagis au différents terrains. Les voitures peuvent aussi avoir des boost de vitesse.

Dans le second commit: "ontrol voiture+drift commit"
On été ajoutés les contrôles de la voiture 1 avec les flèches, ainsi que les mécaniques de drift

Dans le commit suivant: "Drift adaptatif au terrain"
La mécanique du drift a été complètement changée pour être plus réaliste, de plus, la physique de la voiture s'adapte deshormès au terrain sur lequel elle évolue.

Aucune ia n'a été utilisée pour ces etapes, seulement l'aide de visual studio code qui fini les lignes avec TAB.
